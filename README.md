# Agenda de Contatos Java

Projeto desenvolvido para aplicar conceitos de:

- Organização de pacotes
- Orientação a Objetos
- Encapsulamento
- Collections
- Arquitetura em camadas

## Tecnologias
Java 26

## Funcionalidades
✔ Cadastrar contato
✔ Listar contatos
✔ Buscar por nome
✔ Atualizar contato
✔ Excluir contato

## Conceitos aplicados
- Classes
- Objetos
- Construtores
- Encapsulamento
- SOLID
- Arquitetura MVC

### Desafios
- Validar telefone
- Validar e-mail
- Ordenar alfabeticamente
- Buscar por nome parcial
